02 · 데이터와 기억

학습·메모리·기록은
서로 다른 문제입니다.

모델 개선을 꺼도 대화가 자동 삭제되는 것은 아닙니다. 반대로 채팅을 지워도 저장된 메모리가 별도로 남을 수 있어 각각 확인해야 합니다.

01

모델 개선 참여

데이터 제어

설정 → 데이터 제어 → ‘모두를 위한 모델 개선’ 끄기

  • 개인 계정에서 대화가 모델 개선에 사용되는 것을 원치 않을 때 확인합니다.
  • 이 설정을 꺼도 일반 대화는 채팅 기록에 계속 표시될 수 있습니다.

교육 포인트 · “학습 거부”와 “저장·기록 삭제”는 같은 기능이 아닙니다.

02

임시 채팅

민감정보 금지

임시 채팅은 기록·메모리 생성을 제한하는 용도

  • 임시 채팅은 일반 기록에 남지 않고 메모리를 만들지 않습니다.
  • 그러나 안전 모니터링을 위해 일정 기간 보관될 수 있으므로 개인정보 입력 허용 기능으로 보지 않습니다.

교육 포인트 · 임시 채팅을 “보안 모드”로 오해하지 않도록 안내합니다.

03

메모리

개인 맞춤

설정 → 개인 맞춤 설정 → 메모리 관련 항목 확인

  • 저장된 메모리 참조와 채팅 기록 참조는 필요에 따라 끌 수 있습니다.
  • 다른 업무에서 과거 정보가 재사용되는 위험을 줄이는 데 도움이 됩니다.

교육 포인트 · 업무 공용 계정이나 민감한 프로젝트에서는 특히 보수적으로 설정합니다.

04

저장된 메모리

직접 삭제

설정 → 개인 맞춤 설정 → 메모리 관리

  • 기존 저장 내용을 확인하고 불필요한 항목을 삭제합니다.
  • 채팅을 삭제해도 그 대화에서 생성된 저장 메모리가 별도로 남을 수 있습니다.

교육 포인트 · 완전히 제거하려면 관련 채팅과 저장 메모리를 각각 점검합니다.

03 · 공유와 연결

내 계정 밖으로
이어지는 길을 점검합니다.

대화 자체보다 링크, 연결 앱, 권한에서 외부 노출이 생기기 쉽습니다. 쓰지 않는 연결은 해제하고 공유는 최소화하는 편이 안전합니다.

05

대화 기록

업무 종료 정리

프로젝트 종료 시 불필요한 대화·첨부 파일 정리

  • 계약·인사·상담 등 민감한 업무는 조직의 보존 정책을 먼저 따릅니다.
  • 삭제가 필요한 대화는 정기적으로 점검합니다.

실무 원칙 · “언젠가 쓸지도 모른다”는 이유로 모든 기록을 남기지 않습니다.

06

공유 링크

외부 노출

공유가 필요할 때만 생성하고, 사용이 끝난 링크는 회수

  • 링크를 가진 사람이 콘텐츠에 접근할 수 있으므로 민감한 대화는 공유하지 않습니다.
  • 기존 공유 링크 목록을 주기적으로 검토합니다.

실무 원칙 · 복사·붙여넣기보다 공유 링크가 더 넓게 퍼질 수 있다는 점을 교육합니다.

07

외부 앱 연결

권한 관리

사용하지 않는 앱·플러그인 연결 해제 + 권한 재검토

  • 연결 앱은 서비스별 권한과 보존 정책이 따로 적용될 수 있습니다.
  • 업무상 필요한 데이터 범위만 허용하고 사용이 끝나면 연결을 정리합니다.

실무 원칙 · 편리함보다 “접근 범위가 어디까지인가”를 먼저 확인합니다.

08

계정 보안

다중 인증

설정 → 보안 → 다중 인증 활성화

  • 로그인 시 두 번째 인증 단계를 추가해 계정 탈취 위험을 낮춥니다.
  • 필요하면 모든 기기에서 로그아웃 기능도 함께 점검합니다.

실무 원칙 · 비밀번호 유출을 가정하고 두 번째 방어선을 만듭니다.
