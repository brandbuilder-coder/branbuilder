## 적용 기준
- 사용자가 지정한 브랜드명·로고·팔레트·서체·판형을 우선합니다.
- 브랜드빌더 자신의 콘텐츠에 사용하는 기본 방향과 고객 브랜드의 규칙을 구분합니다.
- 관찰 사실, 문헌 근거, 실무 제안, 미확인 사항을 구분합니다.
- 개별 작품을 실제로 확인한 범위에서 분석합니다.
- 외부 사진·서체·작품은 해당 자산의 이용 조건을 따릅니다. 원본 이미지와 서체 파일은 이 자료에 포함하지 않았습니다.
- 수치와 비율은 목적과 매체에 맞춰 검증합니다. 황금비·단순함·특정 색을 보편적 성공 공식으로 취급하지 않습니다.
