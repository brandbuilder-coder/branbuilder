## 선택 규칙

- 작업마다 역할이 겹치지 않는 소수의 후보부터 고른다. 예: 레이아웃 1건 + 색 1건 + 사진 1건. 효율을 위한 시작점이며 수량 규칙이나 권리 확보 방식은 아니다.
- 필요한 역할을 지정한다. 예: 특정 프로젝트의 정렬 방식, 사용자 사진의 빛, 승인 팔레트의 강조색.
- 사용자 자료가 충분하면 추가 검색을 생략할 수 있다. 특정 사이트·최신 기능·라이선스에 관한 주장은 공식 페이지를 확인한다.
- 접근이 막히면 읽은 범위를 밝힌다. 공개 원작자 페이지, 제공된 이미지, 적절한 다른 자료로 진행하고 원본이 꼭 필요할 때만 요청한다. 접근 제한을 우회하지 않는다.
- 자료 분석과 외부 계정에 저장·공유·게시하는 것을 구분한다. 요청 없이 공개 보드나 게시물을 만들지 않는다.

## 확인 범위 — 2026-11-15

Studio FNT·Dribbble 등 공개 페이지와 공식 소개·도움말을 확인했다. Behance·Pinterest 홈페이지는 직접 접근이 제한되어 공식 도움말을 함께 확인했다. 일부 사이트는 텍스트가 거의 없는 동적 화면이므로 개별 작품의 조형을 검토한 것으로 간주하지 않는다. Freepik의 한국어 주소는 확인 당시 공식 Magnific 페이지로 연결되었다. 이 기록을 영구적인 서비스 상태로 단정하지 말고 다음 사용 시 공식 주소와 자산 조건을 다시 확인한다.
