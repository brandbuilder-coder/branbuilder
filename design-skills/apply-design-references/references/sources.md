# 근거 문헌과 공식 자료

확인 기준일: 2026-11-15. 공식 소개·공개 본문·공식 도움말을 통해 확인한 근거다. 책 전체를 읽었다거나 확인하지 않은 페이지를 인용하지 않는다. 기능·라이선스는 실제 사용 시 재확인한다.

## 설계 이론과 사진

1. Josef Müller-Brockmann. *Grid Systems in Graphic Design*, 1981. [출판사 Niggli](https://niggli.ch/en/products/rastersysteme-fur-die-visuelle-gestaltung). 근거 범위: 그리드 조직과 2D·3D 응용을 다루는 설계 문헌. 특정 비율의 미적 우월성이나 매출 효과의 증거로 사용하지 않는다.
2. Josef Albers. *Interaction of Color*, 1963. [Josef & Anni Albers Foundation 교육 해설](https://www.albersfoundation.org/alberses/teaching/interaction-of-color). 근거 범위: 주변 맥락에 따른 색 지각과 관찰·실험을 통한 색 교육.
3. Wagemans et al. (2012). “A Century of Gestalt Psychology in Visual Perception: I. Perceptual Grouping and Figure–Ground Organization.” *Psychological Bulletin*, 138(6), 1172–1217. DOI: [10.1037/a0029333](https://doi.org/10.1037/a0029333). [공개 초록](https://pubmed.ncbi.nlm.nih.gov/22845751/), [공개 본문](https://pmc.ncbi.nlm.nih.gov/articles/PMC3482144/). 근거 범위: 지각적 묶임과 도형·배경 조직의 연구 종합. 모든 로고의 선호도·기억률을 설명하는 법칙으로 확대하지 않는다.
4. W3C. [Understanding SC 1.4.3: Contrast (Minimum), WCAG 2.2](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html). 근거 범위: 웹 텍스트 대비 수치와 예외.
5. Nikon. [Composing Photographs](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/composing-photographs). 근거 범위: 각도·거리 변경, 배경 정리, 주제 분리의 촬영 교육.
6. Nikon. [Using Shadows and Light in Your Photographs](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/using-shadows-and-light-in-your-photographs). 근거 범위: 창빛과 그림자로 질감·입체감·분위기를 조절하는 교육. 모든 상황에 동일한 조명·노출을 지시하지 않는다.

그리드·색 교육·촬영은 설계 문헌과 교육 원리, 게슈탈트는 지각 연구, WCAG는 기술 기준으로 구분한다. 이를 함께 활용하는 절차는 이 스킬에서 구성한 실무 체계다.

## 사이트 기능과 자산 사용

- Studio FNT: [공식 프로젝트 목록](https://studiofnt.com/). 구체적인 시스템은 개별 프로젝트의 설명과 시각 자료를 확인한다.
- Behance: [Creative Fields](https://help.behance.net/hc/en-us/articles/204483944-Guide-Creative-Fields), [Moodboards](https://help.behance.net/hc/en-us/articles/204484004-Guide-Moodboards), [Copyright](https://help.behance.net/hc/en-us/articles/204485044-Guide-Copyright-And-Posting-Content-On-Behance). 작품별 조건이 다르며 공개는 재사용 허락이 아니다.
- Pinterest: [Pins](https://help.pinterest.com/en-gb/article/types-of-pins-on-pinterest), [Copyright](https://help.pinterest.com/en/article/copyright). 원출처와 권리자를 확인한다.
- Gradient Hunt: [About](https://gradienthunt.com/about). 공식 설명·조건 확인용.
- WebGradients: [공식 사이트](https://webgradients.com/). CSS 후보 확인용.
- uiGradients: [공식 저장소](https://github.com/Ghosh/uiGradients). 구현·코드 라이선스 확인용. 다른 자산에 자동 적용하지 않는다.
- Unsplash: [License](https://unsplash.com/license). 무료 콘텐츠의 허용·제한을 확인하고 Unsplash+ 등 다른 조건과 구분한다.
- Freepik: [공식 Stock 안내](https://www.freepik.com/stock). 자산 상세의 라이선스·구독 조건·출처 표시 요구를 확인한다. 서비스명·주소가 바뀌면 공식 연결을 따른다.
- Pixabay: [Content License Summary](https://pixabay.com/service/license-summary/). 독립 자산 재판매·배포 등의 제한과 인물·상표 등 추가 권리를 확인한다. 상표·로고 사용 허락으로 확대하지 않는다.

내부 참고 분석과 완성물에 이미지를 넣는 사용은 별도로 판단한다. 외부 자산을 삽입할 때 해당 조건을 확인하고 필요한 표시를 남긴다. 조건이 미확인이면 승인된 사용자 자산이나 직접 제작한 대안을 사용한다. 추상적 원리만 분석하는 작업에 불필요한 허가 절차를 추가하지 않는다.
