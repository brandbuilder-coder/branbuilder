# 레퍼런스 분석·전환·검증

## 관찰 카드

실제로 분석한 자료만 기록한다. 표 형식은 필요에 맞게 조절한다.

| 항목 | 기록할 내용 |
|---|---|
| 출처 | 작품명, 작가/스튜디오, 개별 URL, 확인 날짜, 사용 조건 확인 상태 |
| 확인 범위 | 실제 이미지/사용자 첨부/페이지 설명 중 무엇을 보았는지 |
| 선택 목적 | 우리 브랜드에서 해결할 문제 한 가지 |
| 정보 위계 | 가장 먼저 보이는 요소와 이유; 관찰 또는 추정임을 표시 |
| 구조 | 판형, 정렬선, 외곽 여백, 정보 묶음, 상대 위치·크기 |
| 색·활자 | 색 역할, 제공/추출/제안 HEX 구분, 활자 밀도와 행갈이 |
| 사진 | 카메라 높이·거리 관계, 빛·그림자, 주제 점유, 배경 여유 |
| 전환 | 가져올 원리 → 우리 내용·자산으로 바꿀 방법 |
| 검증 | 실제 크기, 작은 미리보기, 가독성, 브랜드 적합성, 출력 상태 |

## 전환식

**브랜드 목적 → 관찰 근거 → 추출 원리 → 새 설계값 → 실제 결과 검증** 순서로 연결한다.

예시: “대표메뉴를 바로 인지” → “참고 사진에서 음식과 배경의 밝기 차이가 크고 위쪽이 단순함” → “주제 분리와 제목 자리 확보” → “우리 메뉴 사진의 배경을 정리하고 제목 영역을 촬영 때 확보” → “작은 화면에서도 음식과 메뉴명이 구분되는지 확인”.

이 예시는 절차 설명용 가상 사례다. 특정 작품을 확인한 분석 결과처럼 쓰지 않는다.

## 카메라 오버레이 훈련

사용자가 제안한 겹쳐 보기 방법을 실무 연습으로 운영한다. 학습 속도 향상이 입증된 정량적 연구 결과라고 주장하지 않는다.

1. 촬영 과제와 판형이 맞는 레퍼런스를 고르고 구도·빛 등 관찰 항목을 정한다.
2. 사용 도구가 중첩을 지원할 때 참고 이미지를 반투명으로 표시한다. 기능을 확인하지 않고 카메라를 제어하거나 오버레이를 적용했다고 말하지 않는다.
3. 수평선, 피사체 외곽 크기, 큰 명암 덩어리, 문구용 여백을 비교한다. 세부 소품까지 일치시키는 것을 목표로 삼지 않는다.
4. 자신의 피사체로 촬영하며 한 번에 높이·거리·빛 방향 중 한 변수를 바꿔 비교한다. 촬영 조건과 바꾼 변수를 적는다.
5. 오버레이를 끄고 같은 원리를 다시 구현한다. 결과를 비교해 어떤 변수가 원하는 인상을 만들었는지 설명한다.
6. 실시간 오버레이가 불가능하면 촬영 후 두 이미지를 나란히 비교하거나 지원되는 편집 도구로 중첩한다. 이미지 편집은 전용 도구와 지침을 따른다.

## 작업별 전달물

- **분석 요청**: 선정 이유, 관찰 카드, 적용 규칙, 확인하지 못한 부분.
- **디자인 제작·수정 요청**: 실제 산출물, 변경 근거, 확인 결과. 프롬프트만 주고 끝내지 않는다.
- **촬영 요청**: 촬영 순서, 높이·거리의 상대적 지시, 빛·배경 설정, 비교 체크. 장비·장소가 미정이면 가능한 범위를 먼저 제안한다.
- **여러 장 편집물**: 공통 마스터 규칙과 내용별 변형, 전체 페이지 검수.
- **로고**: 필요하면 설치된 로고 설계 절차와 결합하고 워드마크·심벌의 가독성·식별성·축소 검증을 추가한다.

## 검수표

| 검사 | 판단할 관찰 |
|---|---|
| 목적 | 가장 중요한 정보가 의도한 우선순위로 구별되는가? |
| 정렬 | 공통 기준선과 여백이 일관되고 예외에 이유가 있는가? |
| 밀도 | 관련 정보가 묶이고 서로 다른 그룹이 구분되는가? |
| 가독성 | 한글 행갈이·자간·행간, 작은 글씨, 색 대비가 실제 크기에서 적절한가? |
| 사진 | 주제의 형태·빛·질감이 목적에 맞고 배경이 경쟁하지 않는가? |
| 브랜드 | 승인 로고·색·서체·톤과 내용이 유지되는가? |
| 매체 | 크롭·잘림·오버플로·해상도·인쇄 또는 화면 조건에 문제가 없는가? |
| 출처 | 삽입한 외부 자산의 사용 조건과 필요 표시를 확인했는가? |

점수표를 원하면 프로젝트용 기준과 가중치를 먼저 정한다. 임의의 점수를 객관적·과학적 미감 수치처럼 설명하지 않는다. 검수 결과는 수행 완료/미실시/수정 필요를 구분한다.
