# 시각 원리와 적용 기준

## 근거를 세 층으로 구분한다

1. **지각 연구·기술 기준**: 근접·유사성·도형과 배경의 분리, 화면 텍스트 대비 등. 적용 범위와 조건을 함께 적는다.
2. **설계 문헌·교육 방법**: 그리드, 색 상호작용, 타이포그래피 위계 등. 설계 도구이며 모든 작품의 아름다움을 보장하는 공식은 아니다.
3. **이번 작업의 실무 가설**: 여백 수치, 강조색 비중, 배치안, 촬영 실험 등. 제안값으로 표시하고 실제 결과로 검증한다.

전체 과정은 브랜드빌더를 위해 구성한 실무 체계다. 학계에서 확립된 단일 이론의 이름으로 소개하지 않는다. 서지 정보는 [sources.md](sources.md)를 참고한다.

## 1. 시각적 위계 — Visual hierarchy

- 먼저 전달할 메시지, 이를 뒷받침할 정보, 행동 유도 순서를 정한다.
- 크기·굵기·명도 차이·위치·주변 여백을 함께 조정한다. 모든 요소를 크게 만드는 방식으로 해결하지 않는다.
- 작은 미리보기에서 무엇이 먼저 보이는지 관찰한다. 의도한 읽기 순서는 가설이며 실제 시선 추적 결과처럼 단정하지 않는다.
- F&B 예: 대표메뉴 인지가 목적이면 음식과 메뉴명을 우선하고 가격·기간·매장 정보는 구매 판단에 필요한 순서로 둔다.

## 2. 그리드와 정렬 — Grid / Alignment

- 외곽 여백, 열, 열 사이 간격, 기준선을 정하고 여러 화면에서 공유한다. 비대칭 구성도 공통 기준선으로 질서를 만들 수 있다.
- 스위스 스타일 요청에서는 명확한 정보 위계, 기능적인 활자, 정렬, 절제된 색 사용을 적용한다. 모든 요소의 중앙 정렬이나 장식용 선으로 대체하지 않는다.
- 열 수와 비율은 내용량·판형·매체에 따라 결정한다. 황금비·3등분·특정 열 수를 보편적 미의 법칙이라고 말하지 않는다.
- 여러 장의 슬라이드는 제목·본문·이미지·캡션·쪽번호의 기준 좌표를 정하고 내용에 맞는 소수의 마스터 구성을 만든다.

## 3. 여백과 묶임 — Negative space / Proximity

- 큰 여백은 정보 덩어리를 분리하고 주목점을 만든다. 글자·행·문단 사이의 작은 여백은 읽기와 묶임을 조절한다.
- 관련 정보의 내부 간격과 다른 그룹 사이 간격을 구분한다. 근접성과 유사성은 서로 영향을 주므로 간격 하나만으로 관계가 결정된다고 단정하지 않는다.
- 여백은 흰색일 필요가 없다. 비어 보이는 사진 배경이나 단색 영역도 기능할 수 있다.
- “여백 40%가 고급” 같은 고정 수치를 쓰지 않는다. 중요도와 실제 크기의 판독성으로 조정한다.

## 4. 비례와 시각적 무게 — Proportion / Visual weight

- 면적뿐 아니라 밝기 차이, 채도, 세부 밀도, 글자 굵기, 가장자리 대비가 주목도에 관여하는지 살핀다.
- 좌표를 x/W, y/H, 요소 크기를 w/W, h/H로 기록하면 다른 판형에서도 비교하기 쉽다. 자동 등비 확대 후에는 다시 배치한다.
- 실제 측정값과 눈으로 추정한 값을 구분한다. “약”, “추정”, “설계 제안”을 필요에 맞게 쓴다.
- 단순화는 핵심 특징을 보존하며 경쟁 요소를 줄이는 선택이다. 장식의 적음만으로 차별성·기억 효과를 보장하지 않는다.

## 5. 색의 역할과 상호작용 — Color roles / Interaction of color

- 색상값과 함께 배경·주요 텍스트·보조 텍스트·강조·상태 등의 역할을 지정한다.
- 색상, 명도, 채도와 인접색을 함께 본다. 같은 색상값도 주변색·면적 관계에 따라 다르게 느껴질 수 있다.
- 따뜻함·차가움·활력·신뢰 등의 인상은 문화·산업·주변색·맥락을 고려한 가설로 표현한다.
- 승인된 팔레트가 있으면 원래 값을 우선한다. 레퍼런스의 배색 역할과 비중을 승인 색으로 재설계한다. 추가색·색조 변형은 허용 여부를 구분한다.
- 이미지에서 뽑은 HEX는 색공간·조명·압축의 영향을 받는 추출값이다. 원 브랜드의 공식 지정색이라고 부르지 않는다.

## 6. 그라데이션 — Gradient

- 시작색·끝색, 중간 정지점, 방향, 선형/방사형, 화면 점유를 기록한다. 구현 매체가 지원하면 보간 색공간도 지정한다.
- 실제 텍스트·사진·버튼과 함께 비교한다. 텍스트 영역에서 가장 불리한 배경 구간의 대비를 확인한다.
- 최종 출력에서 색 띠 현상, 의도치 않은 탁한 중간색, 강조 요소와의 경쟁을 확인한다.
- 웹의 일반 텍스트는 WCAG 2.2 AA 4.5:1, 큰 텍스트는 3:1 기준을 적용한다. 큰 텍스트는 보통 18pt 이상 또는 굵은 14pt 이상이다. 로고 텍스트의 예외와 일반 본문의 요구를 혼동하지 않는다. 실제 계산하지 않았다면 “검증 완료”라고 쓰지 않는다.
- WCAG를 인쇄물의 보편적 미학 공식으로 설명하지 않는다. 인쇄물은 재질·잉크·조명·관찰 거리를 포함해 출력 확인한다.

## 7. 사진의 구도와 빛 — Composition / Lighting

- 카메라 높이, 피사체와의 거리, 수평선, 화면 점유율, 앞·중간·뒤의 층, 문구가 들어갈 공간을 읽는다.
- 원근감은 카메라 위치와 피사체의 거리 관계에 크게 영향을 받는다. 초점거리만으로 특정 원근감이 보장된다고 설명하지 않는다.
- 빛의 방향, 그림자 경계, 반사 하이라이트, 배경과 주제의 밝기 관계를 기록한다. 부드러움은 광원의 상대적 크기 등 여러 조건에 영향을 받으므로 “자연광=부드러움”으로 고정하지 않는다.
- 이미지·메타데이터에 없는 정확한 렌즈·조리개·조명 장비는 추정으로 표시한다. 사용자가 지정한 장비는 구현 조건으로 사용하되 노출값은 현장 조명에 맞춰 제안한다.
- 음식은 대표 재료·익힘·표면 질감이 실제와 맞는지, 공간은 수평·수직과 중요한 구조가 유지되는지 확인한다.

## 8. 브랜드 일관성과 적합성 — Consistency / Relevance

- 브랜드 강점과 전달할 약속을 한 문장으로 정하고 레퍼런스의 선택 이유를 연결한다.
- 정렬·간격·빛 등 추상화 가능한 원리를 자신의 내용과 자산으로 구현한다. 독특한 심벌·레터링·캐릭터·구성 전체를 가져와 독자적인 작업이라고 설명하지 않는다.
- 사용자 자산이나 사용 권한이 확인된 자산을 우선한다. 여러 작품에서 원칙을 뽑았다는 사실만으로 이용 허락이 확보되지는 않는다.
- 동일 규칙을 반복할 부분과 매체별로 달라져야 할 부분을 나눈다. 미감과 전환율·기억률·신뢰 효과를 같은 것으로 취급하지 않는다.
