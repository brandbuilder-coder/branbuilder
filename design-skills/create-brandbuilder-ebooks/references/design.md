# 브랜드빌더 편집 디자인 기준

## 디자인 목표
브랜드를 기억하게 만드는 명확한 위계와 충분한 읽기 공간을 확보하라. 기성 템플릿을 복사하지 말고 콘텐츠의 관계에서 페이지를 설계하라. 아래 수치는 출발점이며 판형·내용·실제 렌더에 맞춰 조정하라.

| 항목 | 기본 기준 |
|---|---|
| 종이/배경 | 화이트 #FFFFFF |
| 주 텍스트 | 블랙 #111111 |
| 강조 | 옐로우 #FFD400 |
| 보조 텍스트 | #555555 |
| 구분선 | #D9D9D9 |
| 색의 역할 | 화이트는 읽기 공간, 블랙은 구조, 옐로우는 핵심 |
| 글꼴 | Pretendard, 없으면 사용 가능한 Noto Sans KR 등으로 대체 후 명시 |
| 본문 | 153×225mm 기준 10.5~11.5pt, 행간 1.55~1.7 |
| 장 제목 | 26~34pt, 굵게, 과도한 자간 축소 금지 |
| 소제목 | 15~18pt |
| 주석 | 8.5pt 이상을 출발점으로 인쇄 가독성 확인 |
| 여백 | 상하 18~22mm, 안쪽 20mm, 바깥 17~20mm |
| 서명 | 정확히 -by Brandbuilder- |

옐로우 위 글자는 블랙으로 배치하라. 흰 배경의 노란 본문이나 노란 배경의 흰 작은 글자를 금지하라. 일반 텍스트 대비 4.5:1 이상, 큰 텍스트 3:1 이상을 확인하라. 색만으로 분류하지 말고 이름·번호·선 형태를 병행하라.

## 레이아웃
- 표지: 한 개의 강한 제목, 짧은 부제, 실제 제공된 로고 또는 문자형 브랜드명, 서명. 장식보다 제목과 여백의 비례에 집중하라.
- 목차: 장 번호/제목/실제 쪽번호를 정렬하고 긴 제목이 쪽번호와 충돌하지 않게 하라.
- 장 시작: 큰 장 번호, 질문 또는 주장, 1~2문장 안내. 의미 없는 백면을 추가하지 마라.
- 본문: 한 면에 하나의 주된 논점. 정의·비교표·사례·체크리스트·도해를 정보 특성에 맞춰 선택하라.
- 워크시트: 답을 쓸 공간은 의도된 공간으로 취급하되 질문마다 작성 목적을 명확히 하라.
- 서명: 표지와 마지막 면에 필수, 본문 하단에는 작게 반복 가능. 실제 저자명이 따로 있으면 저자 표기를 대체하지 마라.
- 러닝헤드와 쪽번호: 본문과 분리하고 재단·하단 안전 영역을 지켜라.

## 이미지·로고·도해
인물 사진은 기본적으로 쓰지 마라. 저자 소개상 필요하고 자료가 있으면 처음과 끝에만 최소 사용하라. 제작 대상 브랜드의 로고가 없으면 브랜드명을 활자로 표시하라. 교육용 유명 브랜드 사례는 logo-examples.md에 따라 실제 로고를 찾아 넣고 가짜 공식 로고를 만들지 마라.
로고 비율과 보호공간을 유지하라. 배경과 대비가 부족하면 허용된 단색 버전 또는 깨끗한 바탕을 사용하라.
개념·단계·비교·흐름은 정확한 벡터 도해나 표로 제작하라. 생성 이미지 안에 긴 본문·수치·로고를 굽지 마라.
참고 작품의 레이아웃 원리를 분석하되 고유 삽화·로고·구성을 그대로 복제하지 마라. 이미지마다 출처와 사용 조건을 기록하라.
폰트 파일을 재배포하면 해당 라이선스를 동봉하라. 폰트가 설치되어 있다는 이유만으로 재배포 권한을 가정하지 마라.

## 형식별 변환
전자책 기본은 세로 책 판형이다. 카드뉴스의 4:5는 홍보용 별도 산출물에만 적용하라.
PPTX는 요청 목적에 따라 16:9 교육 슬라이드 또는 책과 같은 세로 판형으로 지정하라. 페이지 수를 억지로 일치시키지 말고 정보 대응표를 유지하라.
