# 강점 기반 브랜딩 집필 기준

## 관점
브랜딩을 외형 꾸미기로 축소하지 마라. 강점을 발견하고, 고객의 선택 이유로 번역하고, 운영에서 반복해 신뢰를 축적하는 과정으로 다뤄라.
“브랜딩은 나침반, 마케팅은 이동수단”, “브랜딩은 각인, 마케팅은 흔적”은 브랜드빌더의 관점을 설명하는 비유로 사용하라. 보편적 학술 정의나 외부 연구 결과로 포장하지 마라.
브랜드의 본질 → 전략 → 디자인 → 고객 경험 → 운영 기준 → 개선의 연결을 유지하라.

## 독자별 적용
| 독자 | 핵심 질문 | 권장 도구 |
|---|---|---|
| 소상공인·F&B 대표 | 손님이 다시 찾는 실제 이유는 무엇인가 | 강점 증거표, 대표메뉴 선택 기준, 응대 체크리스트 |
| 개인 전문가·강사 | 누구의 어떤 문제를 해결하는 사람인가 | 목적·타깃·강점·지속·채널 5단계 |
| 기업 HR·실무자 | 업무 흐름에서 어떤 판단을 개선할 것인가 | 역할표, 업무 전후 비교, 실습 과제, 평가 기준 |
| 브랜드 담당자 | 약속과 실제 경험이 일치하는가 | 접점 점검표, 메시지 계층, 실행 로드맵 |

## 주장과 사례
- 주장마다 근거, 적용 조건, 바로 할 일을 연결하라.
- 확인된 사실 / 저자의 경험과 해석 / 설명을 위한 가상 사례를 구분하라.
- 공개 허락이 없는 고객사 자료나 개인정보를 예시로 넣지 마라.
- 사용자의 실제 매출·매장 수·성과는 최신 제공 자료로 확인하라. 기억만으로 공개 책에 넣지 마라.
- 예: “메뉴를 줄이면 성공한다” 대신 “주문 비중·조리 복잡도·고객 선택 이유를 확인해 대표메뉴 집중 여부를 판단한다”로 작성하라.
- 연구·법률·가격·제품 기능 등 변동 가능 정보는 최신 원문을 확인하고 기준일을 기록하라.
- 출처가 없는 수치는 지우거나 명확한 가정으로 전환하라. 합성 후기와 허구의 전문가 인용을 금지하라.

## 문장과 장 구성
독자가 알아야 할 정의를 먼저 설명한 뒤 현장 예시를 제시하라. 전문용어는 처음 나올 때 쉬운 말로 풀어라.
문단당 하나의 논점을 유지하고 같은 결론을 표현만 바꾸어 반복하지 마라.
각 장의 끝에는 3개 이내의 핵심 요약, 적용 과제 하나, 판단 질문을 배치하라.
워크시트는 질문 / 적을 내용 / 판단 기준 / 다음 행동을 연결하라.
CTA는 책의 문제 해결과 이어지는 다음 행동 하나로 끝내라. 확인되지 않은 연락처나 신청 링크를 만들지 마라.

## 훅 개발
카피 기획 시 최소 5개의 다른 전략을 사용하라.
- 권위: 검증 가능한 경험이나 판단 기준.
- 구체성: 독자·문제·적용 장면.
- 호기심: 독자가 놓친 질문.
- 반전: 통념의 적용 한계.
- 즉시 이점: 읽고 실행할 수 있는 변화.
각 후보에 작동 이유를 덧붙여라. “무조건”, “매출 보장”, 근거 없는 숫자 대신 실제 책이 제공하는 가치를 약속하라.
