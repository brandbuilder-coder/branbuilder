# 실제 브랜드 로고를 활용한 사례 편집

## 선택과 분석
로고 구성·타이포그래피·색·여백 등 설명할 개념을 먼저 정하고 해당 특성을 분명히 볼 수 있는 유명 브랜드를 선택하라. 모든 책에 같은 브랜드를 기계적으로 넣지 마라.
예: Google은 워드마크와 색의 반복, IBM은 레터마크와 수평선의 리듬, Starbucks는 심벌의 독립적 사용을 관찰할 후보이다. 형태 분석과 공식 제작 의도를 구분하고, 디자이너·연도·전략·성과는 출처로 확인하라.

각 사례에 실제 로고 이미지 / 브랜드명 / 연결 개념 / 보이는 특징 / 브랜드빌더의 해석 / 우리 브랜드에 적용할 질문 / 공식 출처를 배치하라. 내용과 관계없는 장식용 로고 콜라주를 만들지 마라.

## 이미지 확보
공식 브랜드센터·뉴스룸·CI/BI 안내·공식 웹사이트의 자산을 우선 사용하라. SVG 또는 고해상도 PNG를 확보하고 출처 URL, 확인일, 버전, 사용 조건을 sources.md에 기록하라.
공개된 이미지라는 이유만으로 퍼블릭 도메인이나 무제한 재배포가 가능하다고 단정하지 마라. 교육·비평 사례의 맥락을 유지하고 제휴·추천·공식 인증을 암시하지 마라. 실제 사용 조건이 해당 이용을 제한하면 다른 적합한 사례를 선택하라.
파일을 확보하지 못했으면 성공했다고 보고하지 마라. 다른 공식 자산 또는 브랜드 사례로 대체하고, 필요하면 미확보 항목을 설명하라.

## 배치와 내보내기
로고 원본 비율·색상·보호공간을 보존하라. 책의 옐로우 스타일에 맞추려고 타 브랜드 로고를 임의로 재색칠하지 마라. 해설용 선·화살표는 로고 위가 아닌 바깥에 배치하라.
PDF에 이미지를 직접 임베드하라. 외부 링크나 HTML의 원격 이미지 주소만 넣고 완료하지 마라. SVG를 쓰면 최종 PDF에서 벡터가 보이는지 확인하라.
가짜 로고 생성·비슷한 글꼴로 재입력·불완전한 트레이싱을 공식 원본 대용으로 쓰지 마라.
“각 로고의 권리는 해당 권리자에게 있으며, 본문은 디자인 교육·비평을 위한 사례 분석입니다. 제휴·후원 관계를 의미하지 않습니다.”라는 안내와 개별 출처를 넣어라. 안내 문구가 이용 허락을 대신한다고 표현하지 마라.

## 완료 기준
실제 로고가 들어간 페이지를 렌더하여 형태·색·선명도·잘림·출처를 확인하라. 원본 대비 왜곡이 없어야 한다. 추가 페이지가 생기면 목차·페이지 번호·북마크를 갱신하라. 예시 로고를 별도 재배포하는 자산 묶음으로 GitHub에 자동 공개하지 마라.
