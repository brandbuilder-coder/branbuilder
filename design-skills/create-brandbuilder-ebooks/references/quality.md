# 최종 검수

## 내용
- [ ] 독자, 문제, 핵심 약속이 표지·서문·본문에서 일치한다.
- [ ] 정의와 사례, 강점과 근거, 전략과 실행이 연결된다.
- [ ] 가상 사례 표시, 실제 사례 공개 범위, 인용 출처를 확인했다.
- [ ] 통계·성과·날짜를 원자료와 대조했다.
- [ ] 반복·빈 문장·분량 채우기용 부록을 제거했다.
- [ ] 워크시트의 질문에 실제로 답하고 행동할 수 있다.

## 파일 및 시각 검수
- [ ] 모든 페이지를 렌더하고 전체 축소판을 확인했다.
- [ ] 표지·목차·각 장 시작·밀도 높은 본문·표/도해·마지막 면을 확대 확인했다.
- [ ] 한글 글리프, 폰트 포함 여부, 검색/복사 가능한 텍스트를 점검했다.
- [ ] 텍스트·표·이미지가 재단 밖으로 나가지 않고 서로 겹치지 않는다.
- [ ] 제목이 홀로 남거나 표의 헤더와 본문이 부적절하게 분리되지 않는다.
- [ ] 목차 쪽번호와 실제 인쇄 쪽번호, PDF 북마크의 목적지가 맞는다.
- [ ] 대비, 로고 비율, 서명 철자, 여백, 쪽번호 위치를 확인했다.
- [ ] 외부 링크와 내부 이동을 실제로 확인했다.
- [ ] 수정 후 재렌더하고 낡은 최종본을 제공하지 않는다.

## 조건부 검수
BookForge 사용 시 해당 엔진의 qc_gate.py PASS 및 gate-report.json을 확인하라. 직접 조판의 육안 점검을 원작 자동 게이트 통과로 바꾸어 말하지 마라.
PPTX 요청 시 실제 슬라이드를 렌더하고 PDF와 핵심 내용·수치를 대조하라.
EPUB 요청 시 실제 EPUB 검증 결과와 최소 한 개 리더의 레이아웃을 확인하라.

## 보고
qc/report.md에 제작 경로, 최종 파일, 실제 페이지 수, 검사 항목, 수정 내용, 미해결 제한을 기록하라.
하드 오류(글자 깨짐·잘림·잘못된 쪽번호·출처 없는 중요 수치)가 있으면 최종본으로 표시하지 마라.
체크하지 않은 항목은 통과로 보고하지 마라. 완료 여부와 파일 형식의 제한을 구체적으로 밝혀라.
