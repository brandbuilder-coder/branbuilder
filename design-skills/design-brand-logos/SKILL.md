# 브랜드빌더 로고디자인

## 작업 원칙

- 브랜드의 강점과 지속 가능한 운영 기준을 시각적으로 각인하는 관점에서 작업하라.
- 읽힘·식별·의미 적합성·재현성을 함께 판단하라. 외형만으로 브랜드의 신뢰·매출을 보장하지 말라.
- 사용자 지시와 이미 정해진 브랜드명·언어·스타일·컬러·활용 매체를 우선하라. 승인된 방향을 다시 선택하게 하지 말라.
- 먼저 요청의 범위를 판단하라: 스타일 선택, 신규 제작, 기존안 수정, 조형 진단, 이론 설명. 범위 밖의 긴 이론이나 불필요한 기획 절차를 붙이지 말라.
- 고객 브랜드에 브랜드빌더의 블랙·화이트·옐로우를 자동 적용하지 말라. 설명 자료에서만 해당 톤과 Pretendard를 우선 검토하라. 로고 자체에 서명·설명 문구를 임의로 넣지 말라.
- 학술 연구 결과, 전문 설계 관행, 이번 작업의 제안을 구분하라. 황금비·대칭·단순함을 성공의 보편 법칙으로 제시하지 말라.

## 참고자료 선택

- 영문 스타일이나 영문 레터링을 다루면 [영문 스타일과 조형](references/latin-styles.md)을 읽어라.
- 한글 또는 이중언어 로고를 다루면 [한글 구조와 조형](references/hangul-styles.md)을 읽어라. 이중언어 작업에는 영문 자료도 함께 적용하라.
- 제작·진단·수정에는 [설계 원칙과 검증](references/principles-and-validation.md)을 읽어라.
- 연구·책·출처를 설명하거나 특정 효과를 주장하면 [문헌과 근거 범위](references/sources.md)를 읽어라. 최신 서체 정보·사용 조건이나 미확인 사실은 공식 자료를 확인하라.
- 참고자료는 이 스킬에 포함된 텍스트를 사용하라. 이전 대화·임시 경로·별도 PDF 접근을 전제로 하지 말라.

## 1. 최소 브리프를 정리하라

현재 대화와 제공된 자료에서 다음을 확보하라.
- 정확한 브랜드명과 표기: 한글, 영문, 대소문자, 띄어쓰기, 병기 우선순위.
- 대상 고객·업종, 차별적 강점, 지키는 약속, 원하는 인상.
- 주요 사용처: 간판, 패키지, 프로필, 모바일, 인쇄, 자수 등.
- 유지해야 할 요소와 금지 요소, 요청한 산출물.

정확한 브랜드명처럼 제작에 필수인 정보가 없을 때만 짧게 질문하라. 선택적 정보는 합리적인 가정을 밝히고 진행하라. 사용자가 이론이나 스타일만 물으면 이름을 요구하지 말라. 기존 이미지가 필요한 수정 요청에서는 먼저 제공된 원본을 확인하라.

## 2. 구성과 스타일을 분리해 선택하라

다섯 층위를 구분하라.
1. 브랜드 역할: 무엇을 기억시킬지.
2. 구성 형식: 워드마크, 레터마크, 모노그램, 구상·추상 심벌, 결합형, 엠블럼.
3. 문자 구조·계열: 영문 계열 또는 한글 구조와 표현.
4. 표현 속성: 굵기, 폭, 획 대비, 곡률, 끝맺음, 연결, 생략, 도구성.
5. 운영 방식: 기본형, 축약형, 단색형, 가로·세로형, 가변형.

사용자가 스타일 선택을 요청하면 서로 다른 방향 3개를 간결한 표로 비교하라. 각 안에 정확한 명칭, 관찰 가능한 형태, 브랜드 적합성의 이유, 약점, 추천 사용처를 적고 추천안을 밝히라. 스타일을 이미 지정했다면 선택 단계를 생략하라.
즉시 제작 요청이면 이용 가능한 맥락으로 방향을 정해 바로 제작하라. 의무적으로 3개 시안을 만들거나 선택 응답을 기다리지 말라.

다음과 같이 구체적인 설계 명세를 작성하라.
- 한글: “워드마크 / 네모틀 기반 / 민부리 / 낮은 대비 / 둥근 끝 / 열린 속공간 / 간판용 기본형”.
- 영문: “Wordmark / Humanist Sans / Medium / Open apertures / Custom kerning”.

## 3. 의미 - 구성 - 조형 - 지각 - 적용 - 검증으로 진행하라

6단계를 작업의 판단 순서로 사용하되 매번 긴 보고서로 노출하지 말라.
- 의미: 브랜드가 지킬 약속을 시각 선택의 이유로 연결하라.
- 구성: 이름과 심벌의 읽기 우선순위를 정하라.
- 조형: 글자의 구조, 비례, 획과 공간의 규칙을 정하라.
- 지각: 시각 중심·광학 크기·자간·식별 단서를 보정하라.
- 적용: 사용 매체의 실제 크기와 배경을 고려하라.
- 검증: 확인한 결과와 아직 확인하지 못한 사항을 구분하라.

영문은 커닝·트래킹·오버슈트·카운터·어퍼처를 점검하라.
한글은 자모의 결합·받침 밀도·속공간·중심선·음절 사이의 리듬을 점검하라.
한글과 영문의 수치상 높이를 억지로 일치시키지 말고 실제 몸집과 획 농도를 맞추라.
기존 로고 수정은 사용자가 지정한 변경 범위를 중심으로 수행하라. 브랜드명·상징·전체 방향을 임의로 교체하지 말라.

## 4. 요청한 결과물을 실제로 제작하라

- 이미지 제작·편집 요청에는 사용 가능한 이미지 생성·편집 도구와 해당 지침을 적용하라. 이 스킬은 조형 판단을 제공하며 이미지 도구를 대체하지 않는다. 프롬프트만 반환하고 끝내지 말라.
- 필요한 참조 이미지의 파일 경로나 대화 첨부를 도구에 전달하라. 참조 없는 이미지를 보았다고 주장하지 말라.
- 로고 원안 요청에는 읽기 쉬운 정면 구성과 단순한 배경을 기본으로 하라. 목업만으로 원안을 대신하지 말라. 사용자가 투명 배경을 요청하면 도구의 투명 배경 설정을 사용하라.
- 사용자가 지정한 색·비율·배경을 우선하라. 색이 미정이면 단색 조형을 출발점으로 삼을 수 있으나 브랜드 컬러를 임의로 확정하지 말라.
- 출력 후 확인 가능한 범위에서 철자, 누락, 자모 변형, 불필요한 문구와 획의 충돌을 검토하라. 확인하지 못한 것을 검수 완료로 표현하지 말라.
- 래스터 이미지와 편집 가능한 벡터를 구별하라. 이미지 파일의 확장자를 바꿔 SVG·AI 원본이라고 하지 말라. 벡터 제작을 요청받으면 지원하는 벡터 편집·작성 경로를 사용하고 실제 경로·곡선·문자 처리를 점검하라.
- Figma 등 특정 앱을 요청하면 해당 앱의 필수 워크플로를 따르라. 기존 코드·SVG 수정은 그 파일을 우선하라.
- 인쇄·간판 제작 적합성은 해당 사양·견본을 실제 확인했을 때만 확정하라. 시안을 제작용 원본으로 오인하게 하지 말라.

## 5. 결과를 목적에 맞게 전달하라

- 스타일 선택: 3개 방향 비교, 추천 이유, 구체적인 스타일 명세.
- 제작·수정: 결과물, 핵심 설계 의도 1-3문장, 실제로 확인한 검수 내용. 이미지 도구의 응답 규칙을 우선하라.
- 진단: 관찰한 문제 → 영향 → 수정 행동. 이미지에서 관찰한 사실과 추정을 구분하라.
- 가이드 요청: 기본형·축약형, 색·배경, 크기·여백, 금지 변형과 매체별 조건을 정리하라.
- 문헌 설명: 해당 주장 가까이에 출처를 붙이고, 전문 관행과 실무 제안을 실험 결과로 포장하지 말라.

최소 크기·보호 여백·획 두께에 보편적인 숫자를 강요하지 말라. 실제 용도에서 시험해 정하라. 사용자 검증을 하지 않았다면 고객에게 검증되었다고 말하지 말라.
