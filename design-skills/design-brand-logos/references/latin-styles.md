# 영문 스타일과 조형

## 계열 명칭
아래 분류는 대표적인 실무 용어다. 역사 분류와 교육 분류의 경계는 다르며 상호 배타적 표준이 아니다. 인상은 형태·언어·업종·경험에 따라 달라진다.

| 계열 | 관찰 가능한 특성 | 점검 |
|---|---|---|
| Old Style / 올드스타일 | 기울어진 축, 완만한 대비, 연결된 세리프 | 세리프·글자 사이 공간 |
| Transitional / 트랜지셔널 | 수직에 가까운 축, 선명해진 대비 | 가는 획의 재현 |
| Didone / Modern / 디돈 | 강한 대비, 가는 세리프, 수직 축 | 소형·자수의 획 소실 |
| Slab Serif / 슬랩 | 두꺼운 판 같은 세리프 | 속공간과 끝맺음의 밀집 |
| Clarendon / 클라렌던 | 세리프와 본획의 곡선 연결 | 연결부 무게; 슬랩 하위군으로도 분류 |
| Glyphic / Inscriptional / 글리픽 | 쐐기형 끝, 새긴 글자의 성격 | 참고한 역사적 맥락 |
| Grotesque / 그로테스크 | 초기 산세리프의 비례와 개별성 | 글자 간 차이와 통일 |
| Neo-grotesque / 네오 그로테스크 | 낮은 대비, 규칙적 구조 | 경쟁 브랜드와 유사성 |
| Geometric Sans / 기하학 산세리프 | 원·직선 등 기하 형태 기반 | 곡선·획의 광학 보정 |
| Humanist Sans / 휴머니스트 산세리프 | 필기 흔적, 열린 구조 | 글자 구별과 어퍼처 |
| Formal Script / 포멀 스크립트 | 정교한 필기와 연결 | 장식 획 충돌 |
| Casual / Brush Script | 자유로운 필기, 도구의 압력·속도 | 흐름과 판독 균형 |
| Blackletter / 블랙레터 | 꺾임·세로획이 강한 역사적 형태 | 문화적 연상과 친숙도 |

Old Style 안의 Humanist Serif와 Garalde를 별도로 나누는 체계도 있다. Modern은 이 문맥에서 최신 유행이 아닌 역사적 계열이다. 한글의 고딕을 영문 브리프에 Gothic으로만 적으면 Blackletter와 혼동될 수 있으므로 Sans Serif와 구체적인 특성을 병기한다.

## 교차 속성
- Rounded: 끝·모서리의 둥근 처리.
- Condensed / Extended: 폭의 차이. 가로 축소와 전용 폭 설계는 다르다.
- Monoline: 거의 균일해 보이는 획. 실제 좌표상 동일 두께만을 의미하지 않는다.
- Stencil, Inline, Outline: 끊김, 안쪽 선, 윤곽선의 처리.
- Ligature: 글자 연결; 구조적 필요와 판독을 함께 검토한다.
- Negative Space: 빈 공간을 이용한 형태; 숨은 그림을 못 찾아도 기본 로고가 기능하는지 본다.
- Display: 큰 크기의 제목 등에 쓰는 용도.
- Monospace: 글자별 자리 폭이 같은 간격 체계.

## 조형 보정
기본 간격을 정한 뒤 특정 글자쌍의 커닝을 조정한다. AV·To 등 눈에 보이는 빈 공간을 확인하고 실제 크기로 검토한다.
Cap Height와 X-height, Baseline을 구분한다. O와 같은 곡선이나 뾰족한 글자에 필요한 Overshoot는 사용 크기·서체에 맞춰 조정한다.
Counter는 내부 공간, Aperture는 열린 부분이다. 작은 크기에서 e·c나 B·O가 서로 혼동되지 않는지 확인한다.
대문자면 권위, 소문자면 친근함이라는 고정 공식을 사용하지 않는다. 실제 브랜드 이름의 윤곽과 리듬으로 비교한다.
