# 브랜드빌더 네이버플레이스 분석프로그램

네이버 플레이스 고객리뷰를 다음 5개 결과로 전환하는 반응형 단일 페이지 웹앱입니다.

1. 고객리뷰: 날짜·별점·리뷰 내용·출처 URL
2. 리뷰분류: 긍정 / 개선동반 긍정 / 부정 / 중립 / 분석 제외
3. 개선과제: 우선순위·대표 고객 신호·실행안·점검 KPI
4. SNS콘텐츠계획: 반복 긍정 주제·훅 5안·작동 이유·촬영 구성·CTA
5. 요약대시보드: 핵심 KPI·반복 강점·개선 신호

제작자: **Brandbuilder**

## 사용법

- 상호와 네이버 플레이스 주소를 입력합니다.
- `.xlsx`, `.xls`, `.csv`, `.json`, `.txt` 리뷰 파일을 업로드하거나 리뷰 원문을 붙여 넣습니다.
- `분석 실행`을 누릅니다.
- 대시보드·리뷰 분류·SNS 기획·개선 리포트를 확인합니다.
- `엑셀 리포트 다운로드`를 누르면 5개 시트의 `.xlsx` 파일이 생성됩니다.

권장 업로드 열은 `날짜 / 별점 / 리뷰 내용 / 출처 URL`입니다. 첨부된 기존 Brandbuilder 리포트의 `고객리뷰` 시트도 자동 인식합니다.

## URL 자동수집 API 규격

정적 웹 브라우저는 타 도메인 페이지를 직접 읽는 데 제한이 있으므로, 자동수집은 별도 서버 API를 연결하는 구조로 분리했습니다.

요청:

```http
POST /collect
Content-Type: application/json
```

```json
{
  "placeUrl": "https://naver.me/...",
  "businessName": "상호",
  "limit": 100
}
```

응답:

```json
{
  "reviews": [
    {
      "date": "2026-09-01",
      "rating": 5,
      "body": "리뷰 내용",
      "url": "https://naver.me/..."
    }
  ]
}
```

## 기술 구성

- HTML / CSS / Vanilla JavaScript
- ExcelJS 브라우저 번들
- 서버 없이 파일 분석·대시보드·엑셀 생성
- 데스크톱·태블릿·모바일 반응형
- 브라우저 로컬 저장 지원
